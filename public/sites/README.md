# ATXFORGE marketing site designs

Two self-contained design directions for the main ATXFORGE site. Each is a single
HTML file with inline CSS and JS — no build step, no dependencies beyond Google Fonts.

| File | Direction | Deployed at |
| --- | --- | --- |
| `forge-steel.html` | Steel grey + temper blue, forge/anvil metaphor, cooling-ingot urgency tool | https://atxforge-steel.vercel.app |
| `daylight.html` | Light, bold, high-interaction: robot mascot, tap-through chat, idea board, fireworks | https://atxforge-daylight.vercel.app |

Each one also serves from this app at `/sites/forge-steel.html` and `/sites/daylight.html`.
